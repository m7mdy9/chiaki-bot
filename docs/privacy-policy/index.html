Agreement

  • By inviting Chiaki Bot, adding it to your apps or using any of its commands you agree to the following Privacy Policy.

Data Access & Collection

  • Please make notice that Chiaki Bot does not have access to your real life personal data, and you shouldn't attempt to input any identifiying data into Chiaki Bot's commands or any other Discord Bot.

What Data Chiaki Bot has access to

  • Chiaki Bot having access to specific data does not mean that it stores that data, it's what Chiaki Bot can view due its set "intents" in Discord, which results in that data to be cached in Chiaki Bot's volatile memory.
  • There are most of the important data cached by Chiaki Bot:
    • Identifiers such as: User IDs, Server (Guild) IDs, Channel IDs, Role IDs.
      • These are cached as they are what allows Chiaki Bot to function properly and distingush server settings stored in it's Database.
    • Message Content: Text of messages sent, deleted or edited.
      • Chiaki Bot does not log or store any messages sent, however messages deleted or edited are logged into the modlog channel in a server if they have it turned on, and they are NOT collected or stored anywhere else.
    • User-Generated Content and Custom Configurations such as: The text you select in /reportcard, reports you send via /report user or /report bug and configurations such as /modlog settings or /welcome message
      • Chiaki Bot accesses this via a MongoDB database.

What Data We Collect

  • Chiaki Bot collects some data that is deemed necessary for functionality and reliability of its commands and events.
  • This data is securely stored in a MongoDB database, and is only accessible to your Developer Team, even MongoDB's employees can not view our data without restriction, MongoDB also claims priority for security.
  • This is the data that is collected and stored until it is no longer deemed necessary by us or is automatically deleted when its no longer needed:
    • Server (Guild) IDs: This is stored with almost all server related customized configuration such as modlogs and welcome message, without this Chiaki Bot wouldn't be able to tell server configuration apart.
    • User IDs: This data is stored with specific commands that require storage of UserID, such as reporting, setting your own /reportcard, etc.
    • Usernames: This data is ONLY stored when the /votingtime start is used, it stores userNames of the people in the vote, which allows for making the voting functionality work and stay reliable.
    • User-Generated Content and Custom Configurations: such as text you input in /reportcard, or toggles you set on or off in /modlog settings and the ID of the channel you select in that previously mentioned command.
  • This data is mostly deleted when it is no longer relevant, and if Chiaki Bot is online while it's kicked out of/leaves a server, Chiaki Bot goes through its models and deletes almost all collected data relating to that guild.

How We Use Your Data

  • We do not sell or share your data to anyone, data stored in Chiaki Bot's Database is kept in Chiaki Bot's database and doesn't touch the database of a data broker or another entity.
  • We will not use your data to harrass, make fun of or blackmail you, these are illegal uses of data and would result in us getting terminated.
  • We use the collected data purely for Chiaki Bot's Core Functionality and Debugging.
    • Without the collected data, it would be as if Chiaki Bot lost its memories whenever it restarts and admins would have to reconfigure the modlogs and other commands from zero.

Data Storage & Security

  • All Data collected by Chiaki Bot is stored securely in Chiaki Bot's MongoDB Database.
    • MongoDB promises utmost security and claims that even their employees do not have unrestricted access to this DB, and they may only access it if there are real serious issues they need to take care of.
  • Chiaki Bot does not retain any information outside of warnings (which Server Owners may request for deletion), reports whether it's user or bug reports, and blacklists.
  • If Chiaki Bot is online while it gets kicked out of a server/leaves a server, it goes over most of its models and deletes data relating to that Server's ID.
  • While we will try our best to make Chiaki Bot's collected Data secure and we will take reasonable precautions we know of to make that happen, no system is a 100% secure.
    • If you disagree, please feel free to view recent Database leaks and how big some of these entities get their databases leaked.

Third-Party Data Sharing

  • We do not share Data with third parties.

User Rights & Data Deletion

  • Users may request deletion of their collected data, directly from the Developer Team, you will find us in our Support Server
    • Keep in mind that not all data will be deleted as they will cause issues with Server Owners, such as /warning data and blacklist data, however if you specially request for that and it's deemed by us that it was used inappropriately we may delete it from there too.
  • Server Owners may request deletion of their collected data, directly from the Developer Team, you will find us in our Support Server
  • If Chiaki Bot is online while it gets kicked out of a server/leaves a server, it goes over most of its models and deletes data relating to that Server's ID.
