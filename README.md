# Chiaki Nanami Bot
[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/X3X624BRKS)
## Description
Chiaki-Bot is your all purpose Discord Bot inspired from **'Chiaki Nanami'** from [Danganronpa 2: Goodbye Despair](https://danganronpa.fandom.com/wiki/Danganronpa_2:_Goodbye_Despair).

Chiaki Bot comes with a set of Danganronpa themed such as /votingtime start, /execute, /reportcard, /introcard and much more! It also comes with many other commands to help you moderate yourself!

For more, run the /help command or **[Join Our Support Server](https://discord.gg/rvyApbfnGk)** 

*This bot is an unofficial, non-profit fan project. It is not affiliated with, endorsed by, sponsored by, or otherwise associated with Spike Chunsoft or the creators of the Danganronpa franchise.*

## Packages
Chiaki-Bot runs on the [Node.js](https://nodejs.org/) JavaScript Runtime, and is completely written in JavaScript.
The Bot utilizes mainly the [discord.js](https://discord.js.org/) Package to communicate and interact with Discord's API.

The Bot utilizes other packages, they are all included within the package.json file.

## Database
Chiaki-Bot uses [MongoDB](https://www.mongodb.com/) as it's primary Database, and the [mongoose](https://mongoosejs.com/) package is utilized for easier interaction with the MongoDB API.

## Production and Testing
There are two branches currently within the Bot's Repository on Github: `main` and `testing`.
Main is the main Production Repo, while testing is the Repo where testing will occur.
